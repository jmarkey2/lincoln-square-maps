# The Remaking of Lincoln Square

An interactive map by Jake Markey comparing historical plans and aerial imagery of Lincoln Square, Manhattan, from 1924 to 2024. Select two maps, blend them with the slider, and toggle the urban renewal boundary.

Created for Day 8 of the [2026 30 Day Map Challenge](https://30daymapchallenge.com/), themed *Utopia*.
